# CADなんです（体験版）

インストール不要の2D CAD「CADなんです」を、ブラウザですぐ試せる体験版です。

▶ **体験版を開く：https://jyumaru.github.io/cadnandesu-trial/**

## できること・できないこと
- ✅ 描く・編集する・図面を開く・印刷する（製品版と同じ）
- ❌ 保存と書き出し（.jcad / DXF / SVG / PNG / CSV）はできません
- 🖨 印刷には透かしが入ります

## アプリとしてインストールする（Chrome・Edge）
体験版を開いて、メニュー →「CADなんです（体験版）をインストール…」。
インストールすると、ブックマークより安定して使えます。ネットがつながらなくても起動できます。
